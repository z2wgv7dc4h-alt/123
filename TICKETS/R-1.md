# R-1 ACE repaint / extend primitive

**Status: Done `4c4d2e6`.** No UI.

`RenderJob.edit = {kind:'repaint', source: Blob, startSec, endSec}`. The backend
sends the take as `srcAudioBase64` with `taskType: 'repaint'`. The bridge's
`apply_source_task` sets `task_type: repaint`, `repainting_start/end`,
`chunk_mask_mode: explicit`, thinking off, and drops `audio_duration`.
`endSec` past the source length extends (ACE pads, see `docs/ACE-NOTES.md`).
