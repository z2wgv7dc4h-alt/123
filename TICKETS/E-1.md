# E-1 Arrangement editor on the take

**Status: Done `9222c20`** for the requested ops — **Duplicate, Delete, Move
(drag reorder), Insert blank N bars** — all on the Studio take, undoable via
`takeHistory`, Studio-only (Sketch shows the buttons disabled). Resize and
extend-anywhere are still open (they came along in the old ticket text).

Splices run on decoded PCM in the browser at exact bar lines (`framesPerBar` /
`frameAtBar` + R-3 `gridOffsetSec`) via `src/ui/lib/arrangeTake.ts`, then ACE
repaints the seam(s). The planner returns one window per join plus a single
covering `repaint` window; because R-1 takes one window per render, the store
sends that covering window in one `edit` (Insert repaints the whole gap +1 bar
each side). Tests: `src/test/arrange-take.test.ts` (exact sample counts +
seam windows) and `src/test/arrange-section-store.test.ts` (splice → one
repaint → Undo without re-splice).

All on the Studio take, all undoable (`takeHistory`), Studio only:
- **Insert** a section (before/after; role, genre, bars): splice silence at a bar line,
  then repaint the gap plus 1 bar each side with the role/genre caption.
- **Delete**: cut the bars, repaint a 1-bar window across the join.
- **Duplicate**: copy the section's audio after itself, repaint the join.
- **Move**: drag to reorder; cut + insert + repaint each join.
- **Resize**: shorter = cut bars; longer = insert bars + repaint.
- **Extend anywhere**, not only the last section.
- Splicing happens on decoded PCM in the browser at exact bar lines (needs R-3's
  downbeat offset); ACE only smooths seams. Takes beyond ~600 s need chunked repaint.

Done when: splice math tests (exact sample counts), one repaint window per seam,
undo restores the previous take, Sketch shows the buttons disabled.
