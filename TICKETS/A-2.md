# A-2 Arrangement builder (same tempo)

**Status: Merged into E-1** (same-tempo arrangement editing).

Lay out blocks (role + genre + bars), e.g. intro → build → drop → dubstep switch → build → drop.
Generate one take at the song tempo, then repaint each block with its role/genre caption
("polish pass"). Optional best-of-N per block. Song map shows block genre and role.
