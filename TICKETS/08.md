# 08 — Sketch: real-break blend control (not just an always-on hardcoded gain)

**File**: `src/core/backends/OfflineStubBackend.ts`,
`src/ui/components/LayersChips.tsx`, `src/ui/hooks/useStudioStore.ts`.

**Change**: `REAL_BREAK_GAIN` in `OfflineStubBackend.ts` is currently a
hardcoded `0.32` constant, always applied for `amen`/`twoStep` pattern
families with no way to disable or adjust it from the UI. Expose it as a
real, adjustable parameter — follow the existing `CPU_CAPABLE` layer-chip
pattern in `LayersChips.tsx` (guitar/solo/extraDrums are already toggled
this way) for an on/off control at minimum; a level slider is a nice-to-
have beyond that. This also unblocks ticket 02 (which needs a real way to
disable the bus for an A/B test, instead of a private-export hack).

**Do not**: remove or change the always-on *default* without the user's
sign-off — the current default is already shipped and the user confirmed
by ear it sounds better ("it sounds a little better"). This ticket adds
control on top of that default, it does not change what ships when a user
touches nothing.

**Done when**: a user can disable or adjust the real-break blend level
from the UI without editing source code, and the default behavior
(on, gain 0.32) is unchanged for anyone who doesn't touch the new control.

**Verify**:
```bash
npx vitest run src/test/simple-process-order.test.ts
```
Add a case there (or a new test file) covering the new toggle/level
control's wiring, matching how the existing CPU-capable layer gating is
tested.
