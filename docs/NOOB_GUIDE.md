# Noob guide — Simple Mode walkthrough

Short path from open → hear → tweak → download. Terms match [GLOSSARY.md](GLOSSARY.md). Tips in the app come from `HELP.*` — each **?** is **What / When / What happens**.

## Journey (equal priority)

1. **Style Ref (optional)** — Drop an MP3/WAV/FLAC **you own**. Tick the owner check. Skip anytime. Not a clone; no YouTube/URLs. Tempo stays ~174.
2. **Generate** (`G`) — One click builds an original browser sketch (CPU). Works with or without a style reference.
3. **Play** (`Space`) — Hear the mix preview. Replay after it ends.
4. **Stem tweak (optional)** — Quick-mute kick/snare/hats/bass on the hero. Full mute/solo/gain under **More**. Play updates live (“Hearing your tweaks”). You do **not** need Generate again for mute.
5. **Again / Vary (optional)** — **Again** = same seed + settings. **Vary** = new seed, same vibe. Ghost buttons after a result — not a 4th primary. (**Surprise Me** and **Favorites** live under More.)
6. **Export** (`E`) — One ZIP for your music software: dry separate-track WAVs + manifest + MIDI. If you remixed, ZIP also adds **`mix_as_heard.wav`** matching what Play heard. Dry tracks always stay.

≤3 clicks: **Generate → Play → Export** with no upload and no tweaks.

## Honesty (read once)

| Claim | Truth |
|-------|--------|
| Sound quality | Browser **CPU sketch** now. Local GPU (ACE on RTX 5080-class) **later** — not live here. |
| Clone? | No. Original output. Style vibe words OK; no catalog rips / stem clones. |
| Your file | Stays in the browser. Owner check required to attach. |
| Export | Dry stems always. `mix_as_heard` only when remixed. |

## Knobs vs mute

- **Mute / solo / gain** → preview only (instant). Export can add `mix_as_heard`.
- **Energy / darkness / chaos / style text / seed** → need **Again**, **Vary**, or **Regenerate** to bake into a new sketch.
