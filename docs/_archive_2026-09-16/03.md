# 03 — Honesty label for real-sample content in the Sketch mix

**File**: `src/core/export/manifest.ts`, `src/core/backends/OfflineStubBackend.ts`.

**Change**: Every other special-case audio source in this codebase has an
honesty label in the export manifest — style reference
(`buildStyleReferenceProvenance`), the `perc` stem (omitted when empty,
noted in manifest), guitar/solo layers ("prompt vibe tags only" warnings
in `AceStepBackend.ts`). The real breakbeat loop added this session
(`buildRealBreakBus` in `OfflineStubBackend.ts`) has none — a render that
used it looks, from the manifest/export side, identical to one that
didn't. Add a manifest field or `warnings`/`notes` entry (matching the
existing pattern — read `buildExportManifest` in `manifest.ts` before
inventing a new shape) stating which real sample loop (if any) was
blended into a given render, and which pattern family triggered it.

**Do not**: invent a new manifest convention. Match the shape and voice of
the existing `styleReference`/`notes`/`warnings` fields exactly — this is
about closing a consistency gap, not adding a new pattern.

**Done when**: `manifest.warnings` or a new `manifest.realBreakLoop` field
is populated whenever `buildRealBreakBus` returns non-null, and empty/
absent when it returns `null`; a test asserts both cases.
