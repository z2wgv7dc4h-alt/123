# Again / Vary / Surprise Me / Favorites

Matches HELP.again, HELP.vary, HELP.surpriseMe, HELP.favorites*, HELP.glossarySeed.

| Control | Behavior | Where |
|---------|----------|--------|
| Again | Same seed + current settings | Transport after result; Regenerate on settings-changed banner |
| Vary | New seed, same vibe knobs | Transport / regen banner |
| Surprise Me | New seed + allowlisted mood template | More only — never hero primary |
| Favorites | Save/recall seed + settings in this browser | More — Favorites panel |

Seed locks song layout. Same seed + same settings → same arrangement.

Knobs vs mute: `HELP.paramsVsMixer` — knobs need Regenerate/Vary; stems update Play live.
