# Listen and modify

Matches HELP.remixPreview, HELP.stems, HELP.remixLive, HELP.glossaryStem.

## What to do

1. Generate then Play.
2. Quick mute on the Simple hero (or full Stems under More): mute / solo / gain.
3. Play updates live — you do not need Generate again for mute/solo/gain.
4. Export ZIP: dry separate tracks always; if remixed, also mix_as_heard.wav matching Play.

## Teaching lines

- Mute key parts — Play updates live. ZIP keeps dry tracks and adds mix_as_heard when you tweak.
- Separate track = one part of the mix. Dry = original file in the ZIP. mix_as_heard = remixed mix matching Play.

## Not the same as arrangement

Energy / Darkness / Chaos / style text need Again or Vary (or Regenerate when settings changed) to bake into a new sketch.

**Rehear:** after mute/solo/gain, hit Play again — no Generate (`HELP.rehear`).

**Perc:** elemental stem **only if perc hits > 0** (no silent `perc.wav`) — mute/solo/gain + mix_as_heard remix include it when unmuted (A3).

## Cycle-9 listen cues

- mixerDirty → pulse **Play** only (never Generate).
- Stem labels show digits 1–4; click label = exclusive solo.
- L loops current section; Z zooms waveform 2×; Esc clears zoom then loop.
- Post-export strip: Favorite / Again / Vary; ZIP includes `sketch_notes.txt`.

**Live vs regen (Audio):** mute/solo/gain = live mid-play (Tone.Channels); Export remux+glue → `mix_as_heard` when dirty. Energy/darkness/chaos/BPM/bars = next Generate only. ACE mute does not isolate stems until LEGO.
